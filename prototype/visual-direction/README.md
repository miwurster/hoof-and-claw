# Visual direction prototype

Throwaway mockups from the visual-direction session; not production code.
Open the HTML files directly in a browser.

- `index.html`: the game screen in every guess state, with the first three logo concepts and the chosen B4.
  Left/right cycles the logo, up/down cycles the state, S opens the logo sheet.
- `logos-b.html`: variants of the split mark, with a colour-vision simulation (V).
- `compare.html`: the current against the proposed Pasture and Rust, side by side.

Verdict: logo B4 (hoof and claw shapes in colour on a Turf tile) and the lighter Pasture `#A9D79B` with Rust `#D0533A`.
The decisions live in `docs/design/visual-direction.md` on `main`.
